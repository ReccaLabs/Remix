- Bugs found and fixed (with tests):
  - Fees tabs had no toast area: `ReminderDialog` calls `useToast`, but `/admin/fees` wrapped its client islands in `IntlIsland` only, so the Invoices tab crashed server-side ("useToast must be used inside ToastProvider") for every user. The component tests wrapped the dialog in a provider themselves, which hid it. Fixed by wrapping the tabs in `PeopleIsland` (`IntlIsland` + `ToastBoundary`), `apps/web/src/app/tenant/admin/(console)/fees/page.tsx`. The regression test is J-09 (a server component page cannot be rendered in jsdom here); say if you want a page-level test added.
  - Test-harness pitfall worth knowing (not a product bug): a Playwright context with `extraHTTPHeaders` (the per-project `X-Forwarded-For`) adds that header to the browser's cross-origin PUT to the slip bucket, so the CORS preflight asks for it and SeaweedFS refuses ("Method PUT is not allowed"). Slip contexts use `scopeClientIp`, which sets the header on app-origin requests only.
